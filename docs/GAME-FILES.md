# فایل‌های بازی (GAME-FILES) — بیاور، قرض نگیر

<div dir="rtl">

## قاعده حقوقی

این برنامه **هیچ فایلی از بازی را شامل نمی‌شود و نمی‌شود** (مپ، تکسچر، موزیک، ویدیو، فونت، آرشیوهای BIG، فایل‌های BIK/CSF…). همه‌ی این‌ها متعلق به Electronic Arts است.

فرمول اجرا:

```
APK (موتور کدباز GPLv3)
+
فایل‌های بازی شما (نسخه قانونی خریداری‌شده: The First Decade / Origin / EA App / CD)
=
نصب قابل بازی
```

## فایل‌های موردنیاز (Zero Hour)

از پوشه نصب ویندوزی شما (مثلاً `C:\Program Files (x86)\EA Games\Command & Conquer Generals Zero Hour`):

| اولویت | مسیر/فایل | نقش |
|---|---|---|
| ⭐ اجباری | `*.big` در ریشه و `Data/` | آرشیوهای داده (INI، مپ‌های داخلی، هنر) |
| ⭐ اجباری | `generalszh.exe` **یا** `Generals.exe` | مُهر نسخه (فقط برای اعتبارسنجی، اجرا نمی‌شود) |
| ⭐ اجباری | `*.csf` (معمولاً `generals.csf` / `generalszh.csf`) | جدول رشته‌ها |
| پیشنهادی | `Maps/` | مپ‌های شخصی |
| پیشنهادی | `Data/Streaming*` | صدا/موزیک |
| اختیاری | `Movies/*.bik` | ویدیوها (حجم بالا) |

برای **جنرالز اصلی** (بدون Zero Hour): همان ساختار با `generals.exe`.

## نحوه انتقال به گوشی

1. فایل‌ها را zip کنید یا مستقیم کپی کنید (USB، شبکه، ابر).
2. در حافظه گوشی جای مستقلی بگذارید، مثلاً: `Android/media/com.obsifox.generals/gamefiles/`
   (این مسیر دسترسی بدون مجوز دارد و با حذف اپ پاک نمی‌شود)
3. در اولین اجرای اپ، ویزارد → «انتخاب پوشه بازی» → همان مسیر را با **پیکر SAF** انتخاب کنید.
4. اعتبارسنجی انجام و نتیجه (فارسی) نمایش داده می‌شود.
5. در صورت خطا: پیام دقیقاً می‌گوید **چه چیزی کم است** — هیچ‌وقت کرش سیاه نمی‌بینید (بخش ۱۴ Master Prompt).

## نکات

- فایل‌ها **کپی** می‌شوند نه جابه‌جا؛ اصل دست‌نخورده می‌ماند.
- خواندن مستقیم از محل انتخابی SAF هم پشتیبانی می‌شود (بدون کپی) برای دستگاه‌های با حافظه کم گزینه «کپی» توصیه می‌شود.
- APK بدون فایل بازی **اجرا نمی‌شود** که بازی کند — فقط منو و لابی را می‌بینید. این رفتار عمدی و حقوقی است.
