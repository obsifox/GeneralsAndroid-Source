# مالتی‌پلیر هات‌اسپات (HOTSPOT MULTIPLAYER)

<div dir="rtl">

## ایده

هیچ سرور اینترنتی لازم نیست. یک گوشی **هات‌اسپات** را روشن می‌کند، بقیه به آن وصل می‌شوند — همان شبکه LAN کلاسیک جنرالز، روی جیب شما.

```
گوشی A (میزبان هات‌اسپات + میزبان بازی)     192.168.43.1
   ├── گوشی B (بازیکن)                      192.168.43.x
   ├── گوشی C (بازیکن)                      192.168.43.y
   └── گوشی D (بازیکن)                      192.168.43.z
```

## پروتکل (پیاده‌سازی فعلی — واقعی، نه فیک)

| لایه | پورت | توضیح |
|---|---|---|
| کشف (Discovery) | **UDP 45777** | میزبان هر ۲ ثانیه پیام JSON broadcast می‌کند: نام بازی، تعداد بازیکن، نقشه، نسخه پروتکل |
| جلسه (Session) | **TCP 45778** | پیام‌های newline-delimited JSON: `hello`، `roster`، `chat`، `ready`، `start`، `ping` |

- روی اندروید broadcast گاهی فیلتر می‌شود → `MulticastLock` گرفته می‌شود و ورود دستی IP هم ممکن است.
- چند اتصال برای اطمینان تست شده‌اند: هات‌اسپات اندروید، روتر خانگی، تترینگ USB (فقط TCP).

## سیر تکامل به مالتی‌پلیر موتور (بخش ۲۰ Master Prompt)

```
[اکنون]  لابی مستقل: کشف + روم + چت + آماده‌شدن  ← همین حالا کار می‌کند
[فاز 16] پل لابی→موتور: خروجی لابی = IP:PORT به LAN API موتور (Winsock→BSD sockets)
         موتور خودش بازی را روی همان سوکت‌ها ادامه می‌دهد؛ هات‌اسپات = LAN واقعی
```

لابی عمداً جدا از موتور نوشته شده (`net/` در Kotlin، پروتکل سندشده) تا:
1. بدون موتور هم قابل تست باشد،
2. وقتی هسته شبکه موتور پورت شد، فقط لایه «پل» اضافه شود،
3. هیچ سرویس آنلاین خارجی‌ای در کار نباشد (رعایت بخش ۲۰: «بدون فیک»).

## قواعد بازی

- حداکثر ۸ بازیکن (مطابق LAN اصلی جنرالز)
- پینگ داخل لابی نمایش داده می‌شود
- میزبان «شروع» را می‌زند؛ شروع واقعی بازی بعد از اتصال موتور فعال می‌شود و تا آن موقع وضعیت صریحاً «در انتظار موتور» است — **هیچ‌چیز فیک نمایش داده نمی‌شود**.

## عیب‌یابی سریع

| مشکل | راه‌حل |
|---|---|
| میزبان دیده نمی‌شود | هر دو گوشی در یک هات‌اسپات باشند؛ در ویزارد ورود دستی IP میزبان (`192.168.43.1`) را بزنید |
| اتصال قطع می‌شود | «بهینه‌سازی باتری» اپ را خاموش کنید تا پردازش پس‌زمینه کشته نشود |
| چت می‌رسد ولی لیست نه | نسخه اپ هر دو طرف یکی باشد (چک نسخه پروتکل) |
