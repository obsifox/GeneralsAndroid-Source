# کنترل‌های لمسی (CONTROLS) — طراحی موبایل‌اول

<div dir="rtl">

قاعده Master Prompt (بخش ۶): «فقط ماوس PC را به لمس مپ نکن.» این سند طرح مرجع کنترل‌هاست؛ پیاده‌سازی نهایی در فاز ۸–۹ به رویدادهای موتور وصل می‌شود.

## نقشه ژست‌ها

| ژست | عمل | یادداشت |
|---|---|---|
| Tap | انتخاب واحد/ساختمان | |
| Tap روی زمین (وقتی انتخابی هست) | فرمان متنی (حرکت/حمله بسته به هدف) | فرمان‌محور contextual |
| Drag انگشت | جعبه انتخاب (box select) | دایره شعاع 24dp نقطه شروع |
| Long-press | منوی فرمان پیشرفته / نگه‌داشتن پیش‌نمایش | hold-to-preview |
| دو انگشت drag | حرکت دوربین | pan |
| Pinch | زوم | 0.5x تا 2.5x، با clamping |
| Double-tap روی واحد | انتخاب همه واحدهای مشابه روی صفحه | |
| Double-tap روی دکمه گروه | پرش دوربین به گروه | control groups |
| لبه صفحه | اسکرول دوربین (اختیاری، پیش‌فرض خاموش) | برای شلوغی لمسی |
| Swipe از لبه راست | باز/بسته پنل فرمان | RTL-aware: لبه منطقی «شروع» |

## حالت‌های نگهداری

- **یک‌دستی:** همه دکمه‌های اصلی در کمان پایین صفحه (سمت دست انتخابی، چپ/راست قابل تنظیم)
- **دودستی:** + مینیمپ در گوشه مقابل
- **تبلت:** پنل‌ها کناره‌نشین، مینیمپ بزرگ‌تر

## حل تعارض ژست‌ها

1. اول انکر تشخیص (تعداد انگشت + فاصله)
2. اگر moving>threshold قبل از timeout → drag/pan/pinch
3. وگرنه پس از timeout → tap/long-press
- آستانه‌ها در تنظیمات (حساسیت لمس/دوربین) و قابل کالیبراسیون.

## دسترس‌پذیری (بخش ۲۳)

- بزرگ‌نمایی دکمه‌ها و متن
- حالت کم‌حرکتی (کاهش انیمیشن)
- حالت چپ‌دست
- ناحیه لمس حداقل 48dp
